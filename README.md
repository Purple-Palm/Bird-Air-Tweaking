# Bird Air Lab

Телеметрия и разбор Bluetooth-протокола личного самоката Bird Air (VA00020) через Web Bluetooth.
Статическая страница без сборки и фреймворков: открыл в Chrome на телефоне — подключился.

**Адрес:** https://purple-palm.github.io/Bird-Air-Tweaking/

Только чтение телеметрии и диагностика. Запись в самокат по умолчанию выключена, характеристики
обновления прошивки (Telink OTA и подобные) страница и инструменты не трогают никогда.

## Включить GitHub Pages (один раз)

1. Pages на бесплатном аккаунте работает только для публичных репозиториев. Если репозиторий
   приватный: Settings → General → внизу «Danger Zone» → Change repository visibility →
   Change to public.
2. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Влей изменения в `main`. Workflow «Pages» (вкладка Actions) выложит сайт за минуту-две.
   Дальше каждый пуш в `main` обновляет сайт сам. Пуши только в `logs/`, `tools/`, `tests/`
   и `*.md` сайт не пересобирают.

Номер сборки (короткий хеш коммита) виден внизу страницы: так видно, что телефон получил свежую
версию. Если нет — потяни страницу вниз, чтобы обновить.

## Открыть на телефоне

1. Chrome на Android (Samsung Internet и браузеры на iPhone не умеют Web Bluetooth) →
   адрес выше → меню ⋮ → «Добавить на главный экран».
2. Полностью закрой приложение Bird: самокат держит одно подключение.
3. «Подключить самокат» → выбери его в списке. Если списка нет, проверь, что Chrome разрешены
   «Устройства поблизости» (Настройки → Приложения → Chrome → Разрешения).
4. Раздел «Инструкция» проверяет браузер и рассказывает, что делать, если самокат молчит.

## Записать лог и отправить его сюда

Один раз: «Данные» → карточка «GitHub: куда отправлять логи». Owner, репозиторий, ветка и
папка заполнены сами. Нужен только токен:

1. github.com → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**
   → Generate new token (или сразу https://github.com/settings/personal-access-tokens/new).
2. Repository access → Only select repositories → `Bird-Air-Tweaking`.
3. Permissions → Repository permissions → **Contents: Read and write**. Остальное не нужно.
4. Вставь токен в поле и нажми «Проверить доступ».

Токен хранится только в этом браузере (localStorage) и не попадает ни в логи, ни в экспорт.
Потерял телефон — отзови токен на github.com.

Запись:

1. Подключись к самокату. Подписка на все уведомления включается сама.
2. Делай действия и в тот же момент жми метку: «Газ», «Отпустил газ», «Тормоз», «Стоп»,
   «Сменил режим», «Фара», «Зарядка вкл/выкл». Каждое действие 3–4 раза с паузой 5–10 с.
3. «Данные» → «Отправить в GitHub»: подпись (по-русски можно, станет латиницей) → «Отправить
   лог в GitHub». Галочка «Обезличить» включена по умолчанию: имя и id устройства станут
   `scooter`.
4. Файл ляжет в `logs/YYYYMMDD-HHMMSS-<подпись>.json`. Большие логи уходят как `.json.gz`,
   очень большие — частями `-part1of3`. Напиши мне «новый лог».

Без интернета лог можно скачать («Скачать лог») и отправить позже: «Загрузить лог…» открывает
`.json`, `.json.gz` и все части лога сразу.

## Как обновляется декодер

Декодер превращает байты в цифры на приборах. Я разбираю логи, нахожу поля и кладу декодер в
`decoders/current.json` с новым номером `version`. Страница при загрузке берёт этот файл с того
же адреса и, если он новее применённого, показывает баннер «В репозитории новый декодер» —
применяется только кнопкой.

Декодеров два: «мой» (то, что ты правишь руками в разделе «Декодер») и «из репозитория».
Переключатель — вверху раздела «Декодер». Если поправить поле в декодере из репозитория, он
станет «моим», а прежний «мой» уйдёт в резервную копию (кнопка «Вернуть прежний «мой»»).
Молча ничего не затирается.

## Инструменты (`tools/`, Python 3)

```sh
python3 tools/analyze_log.py logs/20261014-190211-gaz.json   # или папку, или --new
python3 tools/parse_btsnoop.py btsnoop_hci.log --label bird-app
pip install bleak && python3 tools/ble_logger.py --scan
python3 tools/ble_logger.py --address AA:BB:CC:DD:EE:FF --label pc
```

- `analyze_log.py` — сводка по характеристикам, группы пакетов по заголовку, контрольные суммы
  (XOR, SUM8/16, популярные CRC8/CRC16), кандидаты на поля по реакции на метки, монотонные
  счётчики, советы, что записать ещё. Пишет черновик `decoders/candidate.json`. `--new` берёт
  логи, которых ещё нет в `sources` у `decoders/current.json`.
- `parse_btsnoop.py` — Android HCI snoop log → ATT-операции (записи телефона, уведомления
  самоката, handle → UUID по обнаружению сервисов в логе) в формате лога страницы. Показывает,
  что шлёт приложение Bird и есть ли признаки авторизации. Как снять snoop log — раздел
  «Инструкция» на странице. Нужен полный режим журнала (Enabled), не Filtered.
- `ble_logger.py` — запасной путь с ПК: скан, подключение, подписка на все уведомления, метки
  клавишами 1–8 (как на странице), `m` — своя метка, `q` — сохранить и выйти. Пишет тот же
  формат в `logs/`.
- `check_secrets.py` — проверка, что в репозитории нет токенов GitHub.

## Тесты

```sh
python3 -m unittest discover -s tests   # tools/
npm ci && npx playwright test           # страница: демо, фейковый Bluetooth, GitHub, декодер, вёрстка 390px
```

То же самое гоняет CI на каждый PR (`.github/workflows/tests.yml`).

## Структура

| Путь | Что там |
| --- | --- |
| `index.html`, `assets/` | страница: разметка, стили, скрипт |
| `decoders/current.json` | декодер, который страница предлагает применить |
| `decoders/candidate.json` | черновик декодера от `tools/analyze_log.py` |
| `logs/` | записанные логи (формат — в `logs/README.md`) |
| `tools/` | анализ логов, разбор HCI snoop log, логгер для ПК |
| `tests/` | unittest для `tools/`, `tests/e2e/` — Playwright |

## Открыть на компьютере

```sh
python3 -m http.server 8000
```

и http://localhost:8000/ в Chrome или Edge. Web Bluetooth работает только по https или
с localhost.

## Секреты

Токены GitHub в репозиторий не попадают. Проверка — `python3 tools/check_secrets.py`, она же
идёт в CI и перед выкладкой сайта. Хук перед коммитом включается один раз на клон:

```sh
git config core.hooksPath .githooks
```
