    Отправка команд

    Запись меняет состояние самоката. Случайные байты могут сбить настройки или перевести Bluetooth-модуль в режим обновления прошивки, и руль перестанет работать. Отправляй только команды, которые видел в логе приложения Bird. Характеристики обновления прошивки (OTA) заблокированы.

    Проверка браузера

    Web Bluetooth есть в Chrome на Android и в Chrome или Edge на компьютере. Samsung Internet и любые браузеры на iPhone его не поддерживают. Страницу нужно открыть по https или с localhost. Внутри чата Claude Bluetooth заблокирован, поэтому это отдельный файл.

    Как открыть страницу на телефоне по https
    1. Создай репозиторий на GitHub и загрузи этот файл под именем index.html.
    2. Settings → Pages → Deploy from a branch → main, папка / (root).
    3. Через минуту появится адрес вида https://ник.github.io/репозиторий/. Открой его в Chrome на телефоне.
    4. На компьютере проще: в папке с файлом запусти python -m http.server и открой http://localhost:8000/bird-air-lab.html.

    Шаг 1. Узнать, что у самоката внутри

    1. Поставь nRF Connect for Mobile (Nordic Semiconductor) из Google Play.
    2. Полностью закрой приложение Bird: самокат держит только одно подключение.
    3. Включи самокат. В nRF Connect на вкладке Scanner найди его: самый сильный сигнал рядом, имя может начинаться на Bird или быть серийником BA593…
    4. Нажми Connect. Каждый «Unknown Service» — то, что нам нужно. Сделай скриншоты всех сервисов и характеристик вместе с их свойствами (READ, WRITE, NOTIFY).
    5. У характеристик с NOTIFY нажми значок с тремя стрелками. Если побежали значения, самокат шлёт данные без приложения Bird, и дальше всё просто.
    6. UUID сервисов, которых нет в стандартном списке, впиши в «Данные → Настройки → Свои UUID», иначе Chrome их не покажет.

    Шаг 2. Записать лог с метками

    1. Нажми «Подключить самокат» и выбери его в списке. Подписка на все уведомления включится сама.
    2. Проделай по порядку, каждый раз нажимая метку: постой 10 секунд, плавно дай газ до упора, отпусти, притормози, смени режим двойным нажатием кнопки питания, включи и выключи фару.
    3. Если Bluetooth не гаснет на зарядке, подключи зарядку и нажми «Зарядка вкл».
    4. Скачай лог (раздел «Данные») и пришли его мне. Я найду, где лежат заряд, скорость и ток, и пришлю готовый конфиг декодера. Его вставляешь в «Декодер → Конфиг текстом».

    Если самокат молчит

    Значит, данные он отдаёт только после «рукопожатия» с приложением Bird. Тогда нужно подсмотреть, что приложение ему пишет. Android умеет записывать весь Bluetooth-обмен:

    1. Настройки → Сведения о телефоне → Сведения о ПО → 7 раз нажми «Номер сборки». Появятся «Параметры разработчика».
    2. В «Параметрах разработчика» включи журнал HCI Bluetooth (Enable Bluetooth HCI snoop log). Выключи и снова включи Bluetooth.
    3. Открой приложение Bird и подключись к самокату. Подожди 30 секунд на главном экране, смени режим, включи и выключи фару.
    4. Выключи журнал. В «Параметрах разработчика» нажми «Отчёт об ошибке» (Take bug report) → полный отчёт и сохрани zip.
    5. Внутри найди btsnoop_hci.log (обычно в FS/data/log/bt/ или FS/data/misc/bluetooth/logs/) и пришли мне. Я разберу его и найду команды запроса. Их можно будет отправлять отсюда (раздел «Отправка команд»).

    Чего ждать

    • Скорость и заряд почти наверняка ходят по проводам: их показывает экран на руле. Вопрос в том, выпускает ли их Bluetooth-модуль наружу.
    • Ток, мощность, рекуперация и ток зарядки появятся, только если контроллер их передаёт. Многие дешёвые контроллеры шлют лишь скорость, заряд и коды ошибок.
    • Если тока нет, ставим свою плату: ESP32 и датчик тока INA228 на провод батареи. Она меряет вольты и амперы напрямую, включая рекуперацию и зарядку, и шлёт строки JSON. Эта страница уже умеет их показывать: «Декодер → Поток JSON».
    • Запись в самокат по умолчанию выключена. Характеристики обновления прошивки (OTA) страница не трогает никогда.
