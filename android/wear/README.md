# Bird Air — приложение для часов (`:wear`)

Показывает то, что присылает телефон (модуль `:phone`): по краю круга — полоса мощности (ноль на
12 часах, тяга оранжевой дугой по часовой стрелке, рекуперация синей — против), в центре скорость, под
ней заряд и режим, ниже — запас хода, внизу ватты. Свайп влево — подробности и настройки часов. Сами
часы с самокатом не связываются и ничего в него не пишут.

## Что нового в этой версии

- **Каждое сообщение — сразу.** Экран перерисовывается на каждое сообщение телефона, а не по таймеру;
  таймер (0,5 с) только старит данные до «нет данных с телефона». Снимок, обогнанный более новым (ответ
  на hello, пришедший после потока), пропускается (`Feed.late`).
- **Быстрая мощность.** Дуга и ватты берут `powerFastW` (ток по просадке напряжения, на ~0,6 с раньше
  BMS), когда на телефоне включена «Быстрая мощность»; если быстрого значения нет — `powerW`. На
  странице «Подробно» тогда отдельной строкой ток и мощность по BMS.
- **Плавно.** Дуга движется критически задемпфированной пружиной на каждом кадре: 95 % пути за
  110 мс, без перелёта (скорость к цели ограничена ω·расстояние, от цели — обнуляется, так что дуга
  всегда идёт только к последнему значению и никогда за него). Выкл — прыжок сразу. В ambient всегда
  прыжок. По умолчанию — как на телефоне; на странице «Подробно» чип «Плавно»: как на телефоне → вкл →
  выкл (запоминается).
- **Предупреждения о батарее с телефона** («Заряд на исходе», «Сейчас отключится», «Батарея
  греется», «Батарея перегрета»): плашка вверху вместо времени, дорожка дуги окрашивается (янтарная /
  красная), заряд — не мягче янтарного при «Заряд на исходе» и красный при «Сейчас отключится», даже
  если BMS ещё показывает 11 % и больше. Часы вибрируют: два коротких толчка — WARNING, три длинных на
  полную силу — CRITICAL. Повторно — только когда уровень растёт или через 2 минуты после прошлой
  вибрации (мигающее предупреждение не жужжит каждый раз; висящее — один раз). Только на живых данных.
  Значок поездки на циферблате тоже начинает строку с предупреждения. Подробно — значения: напряжение
  под нагрузкой, температура.
- **Запас хода** — «запас ≈4,2 км» под зарядом (бледнее, пока расход не измерен и это оценка по
  15 Вт·ч/км), подробно — расход и откуда он.
- **Версия часов** уходит телефону в каждом hello и видна внизу страницы «Подробно».
- **Обновление без Bugjaeger** (`WatchUpdater`, `WatchUpdate.kt`, `InstallReceiver`): при запуске (не чаще раза в
  10 минут) и раз в сутки — `version.json` релиза `android-latest`; если `versionCode` больше
  `BuildConfig.VERSION_CODE`, внизу «Подробно» — «Обновить часы (vN)». Скачивание `bird-air-watch.apk` прямо на
  часы: сначала просит Wi-Fi (`requestNetwork`, 8 с), иначе через телефон; переадресации только на GitHub по
  HTTPS, таймауты 15 / 30 с, проценты и скорость, «Отменить» (недокачанное удаляется), после обрыва — докачка
  (`Range`). Проверка: `watchSize` и `watchSha256` из `version.json`, если есть, затем пакет и версия. Установка —
  сессия `PackageInstaller` (запись, fsync, commit с `PendingIntent` на `InstallReceiver`, FLAG_MUTABLE на
  API 31+); окно подтверждения системы (STATUS_PENDING_USER_ACTION) открывается само, иначе — «Подтвердить
  установку». Разрешение «Установка неизвестных приложений» — экран настроек; если его нет — подсказка
  (`appops set … REQUEST_INSTALL_PACKAGES allow` через Bugjaeger). Ничего не ставится без нажатия.

## Обмен с телефоном

- Телефон → часы: `Wire.PATH` (`/birdair/telemetry`), `Wire.encode(Telemetry)`. Настройки телефона —
  в `extras` как 1/0: `"extras":{"fast":1.0,"smooth":1.0}` (`ScooterRepo.forWatch`). Часы также
  понимают эти ключи на верхнем уровне и в объектах `flags` / `ui` / `settings` / `watch`, синонимы
  `fastPower` / `smoothing` и значения true/false, "on"/"off". Сообщение без флага оставляет прежний;
  телефон, который флагов не шлёт, — быстрая мощность (если есть) и плавно. На странице «Подробно» эти
  ключи не показываются.
- Часы → телефон: `Wire.HELLO` (`/birdair/hello`) с UTF-8 JSON
  `{"app":"wear","versionCode":12,"versionName":"0.3"}` (раньше — пустой). Телефон читает его в
  `Versions.watch()`.
- Версия сборки: `./gradlew :wear:assembleDebug -PversionCode=12 -PversionName=0.3` (CI); без них —
  1 / "dev". `BuildConfig.VERSION_CODE` / `VERSION_NAME`.

## Тесты и снимки экранов

```sh
cd android
ANDROID_HOME=/root/android-sdk ./gradlew --no-daemon :wear:testDebugUnitTest :wear:lintDebug
ANDROID_HOME=/root/android-sdk ./gradlew --no-daemon :wear:testDebugUnitTest -Pshots   # PNG в wear/build/shots/
```

JVM-тесты: `LogicTest.kt` (дуга, батарея, режимы, свежесть данных, форматирование, таймеры,
подробности) и `UpdateTest.kt` (пружина: 95 % за 110 мс, без перелёта и отката при новой цели,
независимость от частоты кадров; «Плавно»; флаги телефона; порядок сообщений; быстрая мощность;
предупреждения, вибрация и её пауза; запас хода; hello с версией), `WatchUpdateTest.kt` (version.json,
сравнение версий, когда проверять, SHA-256 и размер, переадресации, докачка, статусы установщика, тексты
кнопки). Снимки (Robolectric, 480×480):
обычные состояния плюс `warning`, `critical`, `ambient-warning`, `warning-reconnecting`, `range-rough`,
`range-mph`, `bms-power`, `details-warnings`, `details-settings`, `update-offered`, `update-downloading`,
`update-ready`.
